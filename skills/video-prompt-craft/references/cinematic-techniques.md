## 镜头运动类型

### 推镜头（Dolly In / Push In）
**运动特征**：摄像机向被摄对象靠近，景别由大变小

**情绪表达**：
- 强化聚焦：引导观众注意力集中
- 情绪升级：增强紧张、期待、恐惧等情绪
- 建立亲密：拉近与人物的心理距离
- 制造压迫：快速推进产生压迫感、威胁感

**适用场景**：
- 人物内心活动揭示
- 关键细节展示
- 情绪高潮到来前
- 威胁或危险逼近

**提示词描述示例**：
- "缓慢推镜头向人物面部靠近，强调情绪的强烈程度"
- "快速推进物体，营造紧迫感与危险感"
- "轻柔推镜头，让观众更贴近这亲密时刻"

---

### 拉镜头（Dolly Out / Pull Out）
**运动特征**：摄像机远离被摄对象，景别由小变大

**情绪表达**：
- 揭示全貌：展示环境和空间关系
- 疏离感：建立观众与角色的心理距离
- 孤独感：人物在环境中的渺小感
- 结束感：段落或故事的收尾
- 反思空间：给观众思考的余地

**适用场景**：
- 场景介绍或结尾
- 孤独、失落情绪表达
- 人物与环境关系的建立
- 情绪转折后的沉淀

**提示词描述示例**：
- "缓慢拉镜头，展现孤独身影周围广阔空旷的风景"
- "从人物面部拉开，展示他在人群中的孤立"
- "轻柔远离，留给观众一种忧郁与距离感"

---

### 摇镜头（Pan / Tilt）
**运动特征**：摄像机固定位置，镜头水平（Pan）或垂直（Tilt）转动

**水平摇镜（Pan）**：
- 环境展示：揭示广阔空间
- 视线跟随：模拟人物目光移动
- 关系建立：连接画面两端的人物或物体
- 时空延展：表现时间的流逝或空间的延展

**垂直摇镜（Tilt）**：
- 高度感：展现建筑物、山脉的高耸
- 权力关系：仰视（人物强大）、俯视（人物渺小）
- 揭示感：从局部到整体或从整体到局部

**提示词描述示例**：
- "缓慢从左向右摇镜头，展现延展的城市景观"
- "从人物双脚向上摇至面部，逐步建立期待感"
- "轻柔摇镜跟随人物的视线扫过房间"

---

### 移镜头（Truck / Slide）
**运动特征**：摄像机沿水平方向平行移动，与被摄对象保持相对距离

**情绪表达**：
- 观察者视角：客观、冷静的观察
- 平行跟随：陪伴感、同行感
- 空间展示：横向展示空间维度
- 对比呈现：展示多个并列元素

**适用场景**：
- 人物行走时的侧向跟随
- 环境细节的横向展示
- 对话场景中的关系呈现

**提示词描述示例**：
- "镜头平行跟随行走的人物，保持观察距离"
- "平滑横向移动，展现一系列门廊与窗户"
- "侧向跟拍镜头跟随人物穿过走廊"

---

### 跟镜头（Follow / Tracking）
**运动特征**：摄像机跟随被摄对象移动，保持相对固定的距离和角度

**情绪表达**：
- 代入感：观众与角色共同经历
- 紧迫感：快速跟随制造紧张
- 陪伴感：建立情感连接
- 沉浸感：身临其境的体验

**常见类型**：
- 前跟（面对面）：建立情感交流
- 后跟（背面）：观察者视角、神秘感
- 侧跟：平衡观察与陪伴

**提示词描述示例**：
- "从背后跟拍，追踪人物穿过拥挤的街道"
- "正面跟随镜头，与行走中的人物保持眼神交流"
- "过肩跟拍镜头，营造共同旅程的感觉"

---

### 升降镜头（Crane / Boom）
**运动特征**：摄像机垂直方向上下移动，常配合其他运动

**升起（Crane Up）**：
- 上帝视角：从个体到群体，从局部到整体
- 情绪升华：喜悦、希望、自由
- 空间扩展：展示环境全貌
- 结束感：段落或故事的升华收尾

**下降（Crane Down）**：
- 进入场景：从全景到局部
- 聚焦个体：从群体到个人
- 压抑感：空间收缩、情绪压抑
- 悬疑感：揭示隐藏细节

**提示词描述示例**：
- "缓慢升起镜头越过城市屋顶，展现都市全貌"
- "从俯视角缓缓下降至独自站立的人物"
- "升降镜头从人群上方升起，捕捉节日氛围"

---

### 环绕镜头（Orbit / Arc）
**运动特征**：摄像机以被摄对象为中心做圆周运动

**情绪表达**：
- 全方位展示：立体呈现人物或物体
- 情绪高潮：强调重要性、仪式感
- 困惑感：围绕人物的困境或迷茫
- 时空凝固：瞬间的永恒化
- 浪漫感：唯美、梦幻的氛围

**适用场景**：
- 人物情感高潮时刻
- 重要的物体或场景展示
- 浪漫、梦幻氛围营造
- 人物内心困境的外化

**提示词描述示例**：
- "360度环绕静止在顿悟瞬间的人物"
- "缓慢圆周运镜，从各个角度捕捉人物"
- "航拍环绕山峰，强调其雄伟孤绝"

---

### 静态镜头（Static Shot）
**运动特征**：摄像机完全静止，画面仅通过内部元素运动

**情绪表达**：
- 凝固感：时间停止、情绪凝固
- 观察感：冷静、客观、抽离
- 压抑感：静态中的张力累积
- 等待感：期待或不安
- 纪实感：真实、质朴

**适用场景**：
- 内心活动强烈时的外部静止
- 紧张对峙场景
- 情绪压抑或等待
- 纪录片风格叙事

**提示词描述示例**：
- "静态镜头，人物静坐不动，只有窗帘随风飘动"
- "固定镜头捕捉房间里的紧张感，对峙中的人物僵立"
- "静止画面观察安静时刻，灰尘在光束中飘浮"

## 景别与情绪关系

### 特写（Close-up / CU）
- **情绪强化**：面部表情、眼神、微动作的放大
- **心理距离**：亲密、压迫、侵略
- **情绪类型**：适合强烈情绪（愤怒、恐惧、悲伤、喜悦）

### 中景（Medium Shot / MS）
- **平衡表达**：人物与环境的关系平衡
- **叙事性**：适合对话、互动、日常活动
- **情绪类型**：中性、温和、叙事性情绪

### 全景（Long Shot / LS）
- **环境关系**：人物在环境中的位置
- **空间感**：孤独、渺小、宏大
- **情绪类型**：疏离、孤独、壮阔、敬畏

### 极远景（Extreme Long Shot / ELS）
- **史诗感**：宏大的空间尺度
- **渺小感**：人物在巨大环境中的微不足道
- **情绪类型**：敬畏、孤独、壮阔、史诗

## 光影动态效果

### 光源移动
**动态类型**：
- 太阳移动：阳光角度变化，影子缓缓旋转
- 人工光源：灯光摇曳、旋转、闪烁
- 火光：火焰跳动，光影快速变化

**情绪表达**：
- 时间流逝感：太阳位置变化暗示时间推进
- 不安感：不稳定光源制造紧张、悬疑
- 温暖感：柔和的暖光移动营造温馨
- 神秘感：局部光源移动制造未知

**提示词描述示例**：
- "阳光缓缓移动扫过房间，影子拉伸旋转"
- "烛光摇曳，在墙壁上投下跳动的阴影"
- "聚光灯束扫过黑暗的房间，揭示场景片段"

---

### 光影变化
**动态类型**：
- 明暗渐变：光线强度逐渐变化
- 阴影拉伸：影子长度和方向变化
- 光斑跳动：透过障碍物的光线跳动
- 色温变化：光线颜色从暖到冷或反之

**情绪表达**：
- 时间流逝：光影变化暗示时间推进
- 情绪转折：光线变化配合情绪转折
- 氛围营造：光影变化塑造特定氛围

**提示词描述示例**：
- "黄金时刻的光线渐渐过渡到清冷蓝色调，影子拉长"
- "光束透过摇曳的树叶，在地面上形成跳动的光影"
- "强烈的午后光线柔和过渡到温暖的夕阳余晖"

## 运镜节奏设计

### 节奏类型
1. **匀速（Constant Speed）**
   - 情绪：稳定、持续、流畅
   - 适用：叙事性场景、情绪铺垫

2. **加速（Accelerating）**
   - 情绪：紧张升级、危机逼近
   - 适用：悬疑、恐惧、紧迫感场景

3. **减速（Decelerating）**
   - 情绪：情绪缓解、冲突化解
   - 适用：高潮后的平静、结局

4. **变速（Variable Speed）**
   - 情绪：复杂、多变、戏剧性
   - 适用：情绪转折、冲突场景

5. **停顿（Pause / Freeze）**
   - 情绪：凝固、强调、震惊
   - 适用：关键时刻、情绪高点

---

### 节奏提示词描述
- "镜头运动从缓慢开始，逐渐加速以匹配不断升级的紧张感"
- "轻柔匀速推进，保持平静氛围"
- "快速拉出后突然减速停止，制造戏剧性揭示"
- "运动短暂停顿后继续，强调这一瞬间"

## 经典运镜案例

### 案例一：孤独感表达
**场景**：黄昏时分，人物独自站在空旷的海滩
**运镜设计**：
- 拉镜头从中景到远景，速度缓慢
- 配合夕阳光线渐弱，影子拉长
- 海浪声音渐强，人物视觉渐小
**提示词**：
```
从中景缓慢拉至远景，渐渐远离孤独的身影。金色夕阳光线逐渐过渡到清冷蓝色，影子在沙滩上拉长。背景中海浪缓缓涌动，人物在画面中逐渐变小。一种孤独与时光流逝的感觉。
```

---

### 案例二：紧张悬疑
**场景**：昏暗走廊，人物听到身后声音
**运镜设计**：
- 推镜头缓慢推进，速度带有停顿感
- 灯光闪烁配合镜头推进节奏
- 焦点从人物背影转到身后阴影
**提示词**：
```
在昏暗走廊中缓慢推近人物背影，推进带有停顿感。头顶荧光灯闪烁，投下不断变化的阴影。人物僵立时镜头暂停，然后继续缓慢推进。焦点从人物转移到身后的阴影。紧张与期待在累积。
```

---

### 案例三：情绪高潮
**场景**：人物经历重大转变，站在城市天台
**运镜设计**：
- 环绕镜头360度环绕人物
- 配合升起，从平视到俯视
- 城市灯光作为背景，时间凝固感
**提示词**：
```
360度环绕站在天台边缘的人物。旋转中镜头缓缓升起，从平视过渡到俯视。背景城市灯光闪烁，头发与衣物在风中轻轻飘动。一个转变与顿悟的时刻，时间仿佛凝固。
```

---

### 案例四：温暖治愈
**场景**：清晨阳光照进房间，人物慢慢醒来
**运镜设计**：
- 静态镜头保持观察感
- 光线变化为主动态：阳光逐渐增强
- 配合人物轻微动作（呼吸、睁眼）
**提示词**：
```
静态镜头观察宁静的卧室场景。清晨阳光逐渐增强，金色光线在床单上蔓延。灰尘颗粒在光束中舞动。人物胸部随呼吸轻轻起伏，眼睑缓缓睁开。薄纱窗帘在晨风中飘动。一种平静、温暖与新开始的感觉。
```

---

### 案例五：追逐紧迫
**场景**：人物在人群中奔跑
**运镜设计**：
- 跟镜头（后跟），速度较快
- 手持感，轻微晃动增加真实感
- 镜头偶尔转向周围环境（障碍物、人群）
**提示词**：
```
快速跟拍镜头从背后追踪奔跑的人物。轻微手持晃动增加紧迫感与真实感。人物穿梭于拥挤街道，行人模糊掠过。镜头偶尔快速转向展示前方障碍物。寒冷空气中呼吸可见，脚步声在路面上响起。追逐中的紧张与绝望感。
```
