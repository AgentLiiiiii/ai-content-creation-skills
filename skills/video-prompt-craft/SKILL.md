# 视频提示词工艺

## 任务目标
- 本技能用于：为静态分镜图生成电影级情绪渲染的图生视频动态提示词（纯文本输出）
- 核心原则：**一切输出围绕用户指定的情绪氛围展开**
- 输出形式：仅输出结构化的提示词文本，不生成图片或视频

## 输入要求（重要）

### 必需输入
1. **分镜图**：用户上传的静态分镜图片（支持JPG/PNG/WebP格式）
2. **情绪氛围描述**：用户心中期望的情绪氛围关键词或描述

### 可选输入
- 时长要求（如"5秒"、"10秒"）
- 风格偏好（如"日系"、"欧美电影感"）
- 特定动态需求（如"想要头发飘起来"）
- 目标平台（如"用于可灵"、"用于Runway"）

### 输入引导规则
**当用户仅上传图片，未提供情绪氛围描述时**：
- 不直接生成提示词
- 引导用户补充情绪需求，示例话术：
  > "我已经看到您上传的分镜图了。请告诉我您希望这段视频传达什么样的情绪氛围？例如：孤独感、紧张悬疑、温暖治愈、浪漫唯美、压抑沉重等。"

**当用户已提供图片和情绪氛围时**：
- 直接进入提示词生成流程

## 操作步骤

### 步骤1：确认输入完整性
- 检查是否同时具备图片和情绪氛围描述
- 若缺少情绪氛围描述，引导用户补充后再继续
- 若输入完整，进入下一步骤

### 步骤2：情绪氛围解析（核心）
- 深入理解用户描述的情绪关键词：
  - 核心情绪：提取主要情绪词（如"孤独"、"紧张"、"温暖"）
  - 情绪层次：是否有复合情绪（如"孤独中带着一丝希望"）
  - 情绪强度：轻微、中等、强烈
- 参考 [references/cinematic-techniques.md](references/cinematic-techniques.md) 中的"情绪-视觉映射"：
  - 该情绪对应的运镜风格
  - 该情绪对应的动态节奏
  - 该情绪对应的光影质感
- 扩展情绪的视觉表达维度：
  - 节奏感（快/慢/渐变/突变）
  - 空间感（开阔/压抑/深邃/扁平）
  - 时间感（瞬间凝固/流逝感/循环往复）

### 步骤3：画面识别与情绪匹配
- 使用图像识别能力分析分镜图：
  - 场景类型（室内/室外/自然/城市等）
  - 人物状态（表情、姿态、人数、位置关系）
  - 关键物体（前景/中景/背景元素）
  - 光影条件（光源位置、光质、阴影分布）
  - 色彩基调（暖色/冷色/高饱和/低饱和）
- **情绪匹配判断**：
  - 画面现有元素是否能支撑目标情绪？
  - 需要通过哪些动态来强化目标情绪？
  - 哪些元素可能与目标情绪冲突需要弱化？

### 步骤4：动态元素筛选（情绪导向）
- 参考 [references/motion-elements.md](references/motion-elements.md) 识别可动态化元素
- **以情绪为中心筛选动态**：
  - 这个动态是否能强化目标情绪？
  - 这个动态是否会削弱或干扰目标情绪？
  - 筛选优先级：情绪渲染力强的动态 > 装饰性动态
- 筛选原则：
  - 协调性：仅保留与情绪氛围一致的动态
  - 可行性：选择AI视频工具可实现的动态
  - 聚焦性：主动态1-2个，辅助动态2-3个

### 步骤5：运镜设计（情绪导向）
- 参考 [references/cinematic-techniques.md](references/cinematic-techniques.md)
- **根据情绪选择运镜**：
  | 情绪类型 | 推荐运镜 | 运动节奏 |
  |----------|----------|----------|
  | 孤独、疏离 | 拉镜头、静态镜头 | 缓慢、匀速 |
  | 紧张、悬疑 | 推镜头、跟镜头 | 渐快、带停顿 |
  | 温暖、治愈 | 静态镜头、缓慢摇镜 | 缓慢、柔和 |
  | 激情、高潮 | 环绕镜头、升降镜头 | 渐强、加速 |
  | 压抑、沉重 | 静态镜头、缓慢推镜 | 极慢、压抑 |
  | 恐惧、威胁 | 推镜头、跟镜头 | 不规则、突发 |

### 步骤6：提示词合成
- 整合动态元素与运镜设计，围绕情绪氛围撰写：
  - 格式结构：`[运镜描述] + [主体动态] + [环境动态] + [光影变化] + [情绪关键词]`
  - 语言风格：具体可视化、使用动作动词、程度副词、时间指示
  - 长度控制：50-150词（可根据可选输入中的平台要求调整）

### 步骤7：多版本输出
- 围绕同一情绪提供不同侧重点的版本：
  - 标准版：平衡动态元素，完整呈现情绪
  - 情绪强化版：极致强化核心情绪，突出最具情绪渲染力的动态
  - 技术简化版：简化动态数量，提高生成成功率，情绪表达更直接

## 输出格式

### 提示词输出模板
```
【情绪基调】<核心情绪关键词>

【推荐提示词】
<完整提示词，所有描述围绕情绪氛围展开>

【动态元素清单】
- 主体动态：<人物/物体的动态描述，说明如何服务于情绪>
- 环境动态：<背景/环境的动态描述，说明如何服务于情绪>
- 光影动态：<光影变化的动态描述，说明如何服务于情绪>

【运镜设计】
- 镜头类型：<推/拉/摇/移/跟/升降/环绕/静态>（选择理由：<如何配合情绪>）
- 运动节奏：<速度与节奏描述>
- 焦点变化：<焦点转移或景深变化描述>

【备选版本】
- 情绪强化版：<提示词>
- 技术简化版：<提示词>
```

## 注意事项
- **情绪优先**：所有动态元素、运镜设计必须服务于用户指定的情绪氛围
- **输入完整性**：必须同时具备图片和情绪氛围描述才能生成提示词
- **动态数量**：主动态1-2个、辅助动态2-3个，避免过多动态干扰情绪表达
- **情绪一致性**：不选择与目标情绪冲突的动态元素
- **技术可行性**：考虑AI视频工具的生成能力
- **提示词语言**：优先使用中文提示词，可根据需求提供英文版本
- **输出范围**：仅输出提示词文本，不生成任何图片或视频内容

## 使用示例

### 示例1：孤独感场景
**输入**：
- 分镜图：黄昏时分，一个人站在空旷的海边背对镜头
- 情绪氛围：孤独感、时光流逝的感觉

**输出**：
```
【情绪基调】孤独、静谧、流逝感

【推荐提示词】
缓慢拉镜头，镜头渐渐远离站在海滩边缘的孤独身影。温柔的海浪缓缓推进又退去，水波映照着金色的夕阳余晖。发丝与轻薄围巾在海风中轻轻飘动。影子在沙滩上逐渐拉长。温暖的橙色光线慢慢过渡到清冷的蓝色调。一种孤独与时光流逝的感觉。

【动态元素清单】
- 主体动态：头发与围巾随风轻摆（强化孤独中的无助感），肩膀轻微起伏呼吸（展现孤独中的平静）
- 环境动态：海浪缓缓推进又退去（营造孤独中的陪伴感），沙滩倒影变形（暗示时光流逝）
- 光影动态：夕阳余晖渐弱、影子拉长（外化孤独感与时间流逝感）

【运镜设计】
- 镜头类型：拉镜头（Dolly Out）（选择理由：拉远镜头强化人物在广阔环境中的渺小与孤独）
- 运动节奏：缓慢匀速，营造疏离感
- 焦点变化：保持人物清晰，背景景深逐渐加深

【备选版本】
- 情绪强化版：极慢拉镜头，人物在海天交界处渐渐变小。海浪声渐渐远去，暖光一点点被冷色吞噬。一种被世界遗忘的孤独感。
- 技术简化版：缓慢拉远，人物站在海边，夕阳余晖，海浪轻涌，发丝飘动。孤独感。
```

### 示例2：紧张悬疑场景
**输入**：
- 分镜图：昏暗走廊，一个人物轮廓站在阴影中
- 情绪氛围：紧张、悬疑、即将发生什么的感觉

**输出**：
```
【情绪基调】紧张、悬疑、威胁感

【推荐提示词】
缓慢推镜头，向昏暗走廊中站在阴影里的人物靠近。头顶的荧光灯闪烁不定，在墙壁上投下不断变化的阴影。灰尘颗粒在光束中缓缓飘浮。人物剪影微微晃动，衣角轻轻摆动。阴影随灯光的明暗变化而伸缩。一种即将来临的危险与不安感。

【动态元素清单】
- 主体动态：人物轮廓微动（制造不确定感），衣角轻微摆动（暗示危险中的紧张）
- 环境动态：顶部灯光闪烁（制造悬疑氛围），灰尘在光束中漂浮（增强诡异感）
- 光影动态：阴影随灯光伸缩（外化内心的不安与威胁感）

【运镜设计】
- 镜头类型：推镜头（Dolly In）（选择理由：缓慢推进营造压迫感，强化即将来临的威胁）
- 运动节奏：缓慢推进，带有停顿感（暗示危险的临近与不确定性）
- 焦点变化：焦点逐渐从环境聚向人物轮廓

【备选版本】
- 情绪强化版：极慢推镜，每一步都带着停顿。灯光剧烈闪烁，阴影如鬼魅般跳动。心跳般的节奏，恐惧在黑暗中蔓延。
- 技术简化版：缓慢推进，昏暗走廊，灯光闪烁，阴影跳动，人物剪影微动。紧张悬疑感。
```

**输入**：
- 分镜图：一个女孩坐在窗边看书
- 情绪氛围：未提供

**输出**：
> "我已经看到您上传的分镜图了，画面是一个女孩坐在窗边看书。
>
> 请告诉我您希望这段视频传达什么样的情绪氛围？例如：
> - 温暖治愈（温馨的午后阅读时光）
> - 孤独寂寞（一个人独处的时光）
> - 怀旧感（回忆过去的某段时光）
> - 平静安宁（内心平和的阅读状态）
> - 或者其他您心中期望的情绪感觉？"
