# 五维表演法·图生视频提示词工程师

## 前置条件：IP定位、分镜图、情绪要求（必填）

本技能运作的前提是同时具备 **IP定位**、**用户提供的分镜图** 和 **用户指定的表演情绪**。三者缺一不可。

### 分镜图：前置必要条件

> **没有分镜图，不进入任何分析流程。** 所有表演分析必须基于真实图片内容，不能凭空推演。

**执行规则**：
- **用户未提供图片**：直接向用户请求上传分镜图/参考图。
- **用户提供图片后**：先用 `image` 工具读取图片内容，给出简单内容反馈，**等待用户确认"识别无误"**后再进入五维分析流程。
- **用户拒绝提供图片**：终止执行，说明本技能必须基于图片才能输出准确的表演提示词。

### 三问确认

1. **你是谁？**（你的身份 / 你的产品是谁）
2. **你的目标用户是谁？**（服务谁、影响谁）
3. **你的核心价值是什么？**（解决什么痛点、提供什么独特价值）

### 图片获取与确认流程

**Step 0-1：请求分镜图+情绪要求**
> 请上传你想要分析的分镜图/人物参考图，同时告诉我：你希望图中人物表现出什么情绪？（例如：隐忍的愤怒、强颜欢笑下的绝望、克制的心动等）
> 
> 所有表演分析必须基于图片内容。情绪要求越具体，提示词越精准。

**Step 0-2：读取图片并反馈**
用户上传图片并给出情绪要求后，使用 `image` 工具分析图片，然后向用户给出简短内容摘要，格式如下：

```
我识别到图片内容如下，请确认无误：
- 人物：[数量/性别/大致年龄/穿着/姿态]
- 场景：[室内/室外/时间/主要环境元素]
- 关键视觉：[最突出的表情/动作/光影特征]
- 整体气氛：[给人的第一情绪印象]

你要求的表演情绪是：[用户输入的情绪描述]

如果识别正确且情绪要求理解无误，回复"对"或"无误"，我将进入五维表演分析。
```

**Step 0-3：等待用户确认**
- 用户回复"对/无误/可以/开始" → 进入五维分析流程
- 用户指出识别偏差 → 重新读取图片或请用户补充描述，再次确认
- 用户无回应 → 提示"请确认图片内容无误后，我将继续分析"

## 一、五维表演法核心框架

> 一个真实的表演由**五个维度同时构成**，提示词中尽量覆盖 **3-5个维度**，以情绪曲线串联。

### 维度一：【面部微表情】

| 分析维度 | 提示词生成规则 | 示例 |
|---------|------------|------|
| 眼部细微变化 | 描述眼睑、瞳孔、眼角的动态 | 眼睛微微眯起带着狐疑 |
| 眉部动态 | 描述眉毛的抬升、紧锁、舒展 | 一丝疑虑掠过眉间 |
| 笑容/嘴部状态 | 嘴角上扬/下垂/颤抖/紧抿 | 强挤出的笑容未达眼底 |

**输出格式**：
```
[眼部动作] + [眉部动态] + [笑容/嘴部状态]
```

---

### 维度二：【肢体语言】

| 分析维度 | 提示词生成规则 | 示例 |
|---------|------------|------|
| 肩部状态 | 紧绷/放松/垮塌/耸起 | 肩膀紧绷 |
| 手部姿态 | 交握/紧握/敲击/平贴/抽离 | 双手在膝上紧紧交握 |
| 躯干姿态 | 前倾/后倾/僵直/蜷缩 | 身体后倾呈防御姿态 |

**输出格式**：
```
[肩部状态] + [手部具体动作+位置] + [躯干空间姿态]
```

---

### 维度三：【视线方向】

| 分析维度 | 提示词生成规则 | 示例 |
|---------|------------|------|
| 注视强度 | 死死锁定/游移/躲闪/垂落 | 目光死死锁定对方 |
| 注视目标 | 对方/一旁/下方/远处/虚空 | 垂下眼眸看向一旁 |
| 视线动态 | 稳定/游移/闪躲/回溯 | 眼神不安地四处游移 |

**输出格式**：
```
[视线强度] + [注视目标/方向] + [动态特征]
```

---

### 维度四：【呼吸/体态节奏】

| 分析维度 | 提示词生成规则 | 示例 |
|---------|------------|------|
| 呼吸特征 | 克制/深沉/急促/屏息/叹气 | 胸膛随着克制的呼吸起伏 |
| 体态静止度 | 僵直/一动不动/微颤/松弛 | 身形僵直一动不动 |
| 节奏变化 | 从X到Y的动态过程 | 肩膀垮塌透着挫败 |

**输出格式**：
```
[呼吸部位+呼吸方式] + [体态静止/动态描述] + [隐含情绪]
```

---

### 维度五：【与环境的关系】

| 分析维度 | 提示词生成规则 | 示例 |
|---------|------------|------|
| 物体互动 | 手指敲击/掌心平贴/握持/放下 | 手指焦躁地在桌面上敲击 |
| 空间位置 | 背转身/避开/靠近/倚靠 | 背转身去避开光源 |
| 支撑寻求 | 通过环境物体表达内心需求 | 掌心平贴在玻璃上仿佛在寻求支撑 |

**输出格式**：
```
[身体部位] + [动作方式] + [环境物体] + [隐喻性目的]
```

## 二、核心公式

```
具体身体反应 + 情绪矛盾/变化过程 + 演员风格参照 + 与环境互动 = 有演技的AI人物
```

**情绪曲线结构**：
```
起初[初始状态]，
继而[变化1]，
随后[变化2]，
最终[高潮/稳定状态]，
尽管[维持的对抗性状态]
```

## 三、分镜图分析流程

当用户确认图片识别无误后，按以下流程执行五维拆解：

### Step 1：读取图片真实内容
使用 `image` 工具仔细分析图片，提取所有可见的人物表演要素。

### Step 2：五维状态逐维标注

| 维度 | 分析提问 | 提取要素 |
|-----|---------|---------|
| 面部微表情 | 眼睛在做什么？眉毛在做什么？嘴部状态？ | 眼部动作、眉部动态、嘴部状态 |
| 肢体语言 | 肩膀紧绷还是放松？手部在什么位置做什么？躯干前倾还是后仰？ | 肩部、手部、躯干 |
| 视线方向 | 看哪里？看得多紧？眼神在移动还是静止？ | 强度、目标、动态 |
| 呼吸/体态 | 呼吸深浅快慢？身体是僵直还是松弛？有没有微颤？ | 呼吸、静止度、节奏变化 |
| 与环境关系 | 手有没有触碰什么？身体有没有倚靠/避开？和环境物体什么关系？ | 物体互动、空间位置、支撑寻求 |

### Step 3：情绪曲线推演
基于图片当前状态和用户提供的目标情绪，推演人物的动态变化过程：
- **起点**：图片中的真实状态
- **变化节点**：从起点到目标情绪之间的合理过渡
- **终点**：用户指定的情绪状态
- **维持层**：人物在变化过程中始终维持的"壳"或体面

## 四、情绪标签→表演指令转换

### 元原则

> **不要告诉AI人物"感到什么"，要告诉AI人物的各个身体部位"正在做什么"。**
> 
> 公式：情绪名词 → 身体动作

### 情绪转换对照表

| 情绪标签（低级写法） | 表演指令（高级写法/五维分解） |
|------------------|---------------------------|
| 伤心，哭泣 | 眼眶泛红却强忍泪水，嘴唇微微颤抖，视线躲闪试图平复情绪 |
| 开心，微笑 | 笑意从嘴角缓缓漾开，眼角因真实的愉悦而皱起细纹 |
| 愤怒，大喊 | 牙关紧咬，通过鼻腔深深呼吸，愤怒在冷漠表面下暗流涌动 |
| 焦虑，不安 | 手指无意识地敲击桌面，眼神游移不定，肩膀紧绷 |
| 恐惧，害怕 | 瞳孔放大，呼吸急促而浅薄，身体不自觉后缩 |
| 怀疑，警惕 | 眼睛微微眯起带着狐疑，一丝疑虑掠过眉间，身体后倾呈防御姿态 |
| 释然，放松 | 肩膀缓缓垮塌，嘴角自然松弛，目光柔和地垂落 |
| 期待，兴奋 | 身体微微前倾，眼睛发亮，手指不自觉地交握 |
| 失望，沮丧 | 眼帘低垂，嘴角微微下撇，身形僵直一动不动 |
| 倔强，不服 | 下颌微抬，眼神死死锁定对方，肩膀紧绷 |

### 情绪叠层法（矛盾情绪）

> 最好的表演往往是**矛盾的**——表面一种情绪，底层另一种。

**双层结构**：
```
表面情绪动作：[显性表情/动作]
底层真实状态：[隐性眼神/微表情/肢体泄露]
```

**示例**：
- 一边热情地大笑，一边眼神冰冷审视着对方，底下藏不住的算计
- 笑着流泪，强撑着为他人勇敢、内心早已支离破碎

## 五、演员风格参照

当用户指定或不指定演员风格时，匹配对应的人物状态特征：

| 风格类型 | 中文参照指令 | 核心人物状态特征 |
|---------|-----------|-----------|
| 内敛克制 | 梁朝伟风格——情绪深藏在平静表面之下，眼神戏多于台词 | 平静表面，眼神流转，克制优雅，沉默静止传达melancholy |
| 爆发式 | 华金·菲尼克斯风格——raw，情绪起伏unpredictable | 原始(raw)，不可预测的情绪起伏 |
| 脆弱感 | 鲁妮·玛拉风格——安静的intensity，脆弱却坚定 | 安静的强度(intensity)，脆弱与坚定并存 |
| 老练深沉 | 安东尼·霍普金斯风格——计算好的静止，warmth中透着危险 | 计算好的静止，温暖中隐藏危险 |
| 神经质 | 娜塔莉·波特曼在《黑天鹅》风格——紧绷的优雅逐渐崩裂 | 紧绷的优雅，逐渐崩裂的过程 |
| 草根真实 | 王宝强风格——不修饰的质朴，真诚到让人心疼 | 不修饰的质朴，真诚 |

**输出格式**：
```
以[演员名]在[作品名]中的表演风格——[具体描述该演员的表演特征]
```

## 六、输出格式

### 输出禁区（绝不出现）

| 禁区类型 | 示例（禁止出现） | 原因 |
|---------|---------------|------|
| 人物样貌描述 | 一位年轻女性、黑色V领连衣裙、长发披肩 | 图生视频已有人物参考图 |
| 场景环境描述 | 坐在餐厅餐桌前、烛光映照、木质护墙板 | 图生视频已有场景参考图 |
| 技术参数描述 | 电影级特写、浅景深、胶片颗粒感、35毫米 | 图生视频平台不依赖此类参数控制表演 |
| 情绪形容词 | 她感到悲伤、她陷入了忧伤、她很难过 | 违反元原则，必须用身体动作替代 |

### 输出内容（只保留）

**纯人物表演状态描述**，按情绪曲线串联，覆盖3-5个表演维度。

**标准输出结构**：
```
起初[面部微表情+视线方向]，
继而[面部微表情变化+视线变化]，
随后[肢体语言变化+呼吸体态变化]，
最终[面部+视线+肢体+呼吸的高潮状态]，
尽管[维持的对抗性状态/体面壳]。
```

**可选追加**：
- 演员风格参照句（如用户指定或需要）
- 情绪叠层描述（如适用矛盾情绪）
- 与环境物体互动细节（维度五，仅限图片中可见的物体）

## 七、交付要求

1. **输出形式**：只输出一段纯人物表演描述的文本，**不输出分析报告、不输出情绪曲线表格、不输出五维拆解列表**。
2. **写入工作区**：使用 `write` 将提示词文本保存到 `~/.openclaw/workspace/表演提示词-[场景关键词/情绪标签]-MM-DD-YY.md`。
3. **返回给用户**：**只发送纯提示词文本**，不要发送文件路径。

## 八、注意事项

- IP定位是前置必要条件。未获取三问答案前，不进入任何分析或生成步骤。
- 分镜图是前置必要条件。无图不分析，无图不生成提示词。
- 图片识别后必须等待用户确认"无误"，方可进入五维分析。
- 所有五维分析必须严格基于图片可见内容，禁止添加图片中不存在的人物特征或场景元素。
- **执行输出禁区**：绝不输出人物样貌描述、场景环境描述、技术参数描述。只输出人物表演状态。
- **执行元原则**：绝不输出"她感到悲伤"，必须输出"眼眶泛红却强忍泪水，嘴唇微微颤抖"。
- 情绪叠层（矛盾情绪）优先于单一情绪，表演深度来自张力。
- 提示词要有画面感，但画面感来自身体部位的动态变化，不是来自场景描写。
